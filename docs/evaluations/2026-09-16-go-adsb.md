# go-adsb reuse for the initial codec

## Decision

Use `kreklow.us/go/go-adsb v0.4.1` behind `internal/adsb` for raw bit access,
parity, callsign decoding, and barometric altitude decoding. Keep its types
inside the package. Implement frame packing, velocity interpretation, and
guarded airborne CPR reconstruction locally.

## Reference reviewed

[Source repository](https://github.com/cjkreklow/go-adsb), tag `v0.4.1`,
commit `bb4588c791a8079d92e22bd56bcd64f89f6c2d45`, inspected on 2026-09-16.
The module declares `kreklow.us/go/go-adsb`, not its GitHub URL as the import
path. It is MIT licensed and depends on `github.com/ccoveille/go-safecast/v2`.
The exact versions and checksums are pinned in the module files.

Inspected files: `adsb/raw.go`, `raw_es.go`, `message.go`, `altitude.go`,
`position.go`, and their test fixtures. No third-party source is copied or
patched in this repository.

## Findings and integration

- Raw messages accept byte slices directly; using the Beast transport package
  is unnecessary. The wrapper requires exactly 14 bytes and DF17 first.
- `RawMessage.Parity` computes CRC, but unmarshalling does not verify it.
  The wrapper compares computed and transmitted values explicitly.
- `Message.Call` maps reserved characters to question marks. The wrapper
  rejects those values and preserves valid spaces.
- `Message.Alt` decodes Q=1 and Gillham altitude. It rejects all-zero altitude;
  the wrapper recognizes that code as unavailable before calling it.
- The module has no message encoder or high-level velocity decoder.
- `DecodeGlobalPosition` assumes its second argument is newest and accepts no
  timestamps or aircraft identity. Its NL table uses a strict comparison at
  87 degrees, returning 1 where the CPR definition specifies 2.
  `CPR.DecodeLocal` also permits reference longitude up to 190 and leaves
  output normalization to the caller.

Local CPR uses the published equations with explicit finite/range checks,
the exact polar cases, address checks, caller-supplied times, deterministic
newest-frame selection, and reference-age/range rules. The API retains no
hidden clock or tracking state. Consumers must still check track plausibility.

## Evidence and limits

Published identification, position, and velocity frames test both decoding and
exact encoding, including CRC. Independent polynomial-division CRC tests
exercise mutated payloads. Rational grid cases include NL=2 at exactly 87
degrees. Further tests cover Gillham altitude, all four velocity subtypes,
unavailable and over-range values, stale pairs, and longitude wrapping.
Fixture sources and expected values are recorded in
[the fixture documentation](../../internal/adsb/testdata/README.md).

The initial position subset is barometric TC9-18; GNSS-height TC20-22 and
surface positions remain outside it. Encoding altitude uses Q=1 only.
The package is a simulator codec, not a complete ADS-B transponder.

Revisit this integration when upgrading go-adsb, expanding the supported
position types, or when upstream supplies an encoder or corrected CPR API.
